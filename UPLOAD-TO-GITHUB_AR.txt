رفع تحديث Dental Chain OS v15.73 فوق المستودع الحالي
====================================================

1) ارفع محتويات هذه الحزمة فوق مستودع Dental Chain OS الحالي (استبدال الملفات المتطابقة، لا تحذف بيانات التشغيل).
2) يجب أن تكون index.html وpackage.json وfirebase.json ومجلدات js وcss وdesktop في جذر المستودع مباشرة.
3) سيبقى نشر Firebase Hosting يعمل بالطريقة الحالية؛ ملفات ويندوز مستثناة من الاستضافة.
4) من GitHub افتح Actions ثم شغّل: Build Dental Chain OS for Windows.
5) بعد النجاح نزّل Dental-Chain-OS-Windows؛ ستجد نسخة تثبيت ونسخة Portable.
6) أول تشغيل لنسخة ويندوز ينشئ قاعدة البيانات في Documents/Dental Chain OS/Data ثم يسجّل الدخول إلى Firebase بالحساب نفسه.

لا تحذف المستودع أو الملفات الأخرى، ولا ترفع ملف ZIP نفسه إلى GitHub.

الترحيل آمن: نسخة المتصفح القديمة لا تُحذف إلا بعد نجاح نسخها إلى IndexedDB. يُستحسن مع ذلك تنزيل نسخة JSON يدوية قبل أول تحديث كما في أي إصدار إنتاجي.
