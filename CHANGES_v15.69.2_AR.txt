Dental Chain OS v15.69.2 — مستكشف صور المرضى

- أزرار الصور أصبحت تفتح قائمة الملفات الموجودة فعلياً داخل مجلد المريض والتصنيف المرتبط بالزر.
- أضيف زر + داخل القائمة لاستيراد صورة أو عدة صور.
- عند الاستيراد تُنسخ الملفات فعلياً إلى مجلد المريض عبر File System Access API.
- تُعاد تسمية النسخة تلقائياً برقم الملف + اسم المريض + نوع العملية + التاريخ والوقت.
- الصور الجديدة لا تتحول إلى Base64 ولا تُحفظ داخل LocalStorage أو Firebase أو سجل المريض.
- بقي LocalStorage مخصصاً لبيانات المرضى النصية والعمل Offline/Online والمزامنة كما كان.
- يمكن فتح كل صورة من القائمة للمعاينة بالحجم الكبير.
- يتطلب Chrome أو Edge على HTTPS، مع ربط مجلد Dental Chain Patients ومنح صلاحية الكتابة.
